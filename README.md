# Banco23: Inteligência de Risco com Machine Learning 🚀

Projeto desenvolvido durante o **Hackathon de encerramento do curso Ada | Elas+ Tech**. O objetivo foi construir um modelo preditivo para 
identificar o risco de inadimplência de clientes, auxiliando na tomada de decisão de concessão de crédito.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python
* **Bibliotecas:** Pandas, Matplotlib, Seaborn, Scikit-learn
* **Modelos:** Regressão Logística e Random Forest
* **Plataforma:** Google Colab e GitHub

## 📊 O Projeto
A análise consistiu em:
1. **Engenharia de Dados:** Criação da métrica `income_commitment_ratio` (Comprometimento de Renda).
2. **Pré-processamento:** Escalonamento de dados para modelos lineares.
3. **Avaliação:** Comparação de performance focada em métricas de negócio.

## 📈 Comparativo de Performance
| Métrica | Regressão Logística (M1) | Random Forest (M2) |
| :--- | :---: | :---: |
| **Acurácia** | 0.98 | 1.00 |
| **Precisão** | 0.98 | 1.00 |
| **Recall** | 0.99 | 1.00 |
| **F1-Score** | 0.99 | 1.00 |

> **Nota:** Priorizamos o **Recall** como métrica principal para garantir que o Banco23 minimize perdas financeiras identificando o maior número possível de clientes de risco.
